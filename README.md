# DataVerse privacy career masterclass

A responsive Next.js landing page for the DataVerse Solutions Data Privacy career transition offer.

## Local development

Requires Node.js 24 or later.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run check
```

The app uses the Next.js App Router and is ready for Vercel’s standard Next.js deployment flow. No environment variables are required.
